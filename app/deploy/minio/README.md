# Ограниченные права MinIO: проверенные срезы

`iam-policies.mjs` экспортирует `policies(env)`: три IAM-документа без секретов.
Имена пяти бакетов берутся из MINIO_BUCKET_* либо anime-*; некорректные имена
и совпадения отклоняются. Генератор ничего не применяет к серверу.

- `provision`: создание и настройка только пяти бакетов для storage_setup;
  чтение versioning/policy/lifecycle, удаление policy, установка policy/lifecycle,
  ListBucket для HEAD. Нет объектных операций, DeleteBucket, PutBucketVersioning,
  ListAllMyBuckets или admin:*.
- `reader`: только GetObject для video/previews. Нет чтения originals,
  загрузки, удаления и изменения настроек бакетов.
- `uploader`: PutObject, ListMultipartUploadParts, AbortMultipartUpload только
  для originals. Позволяет начать, загрузить, завершить и отменить multipart;
  не позволяет читать или удалять завершённый объект.

Это **не готовая политика всех задач web/media**: обработчику видео нужны другие
права, а проверке доступности могут требоваться дополнительные операции. Приложение
пока использует одну пару MINIO_ACCESS_KEY_ID/MINIO_SECRET_ACCESS_KEY; автоматического
выбора трёх учётных записей нет. Не объединять эти политики в root-подобный набор.
Provision — привилегированная операторская роль: возможность менять bucket policy
позволяет открыть доступ к своим бакетам. Её ключи нельзя выдавать веб-приложению.
У uploader PutObject позволяет перезаписывать известный ключ; авторизация и выбор
ключа приложением всё равно обязательны. Это не гарантия «только новая запись».

## Повторяемая проверка

`bash dev/check_storage_local.sh /path/to/minio /tmp/anime-release-check.XXXXXXXX/package /path/to/nginx /path/to/mc`

Четвёртый аргумент включает IAM-режим. Только новый временный MinIO на loopback:
root создаёт три тестовые учётные записи и политики через mc; storage_setup
выполняется под provision, чтение/загрузка — под reader/uploader. Root используется
для контрольных данных и проверки результата, не для проверяемых операций.
Проверка чужого бакета требует настоящий 403, а не любую ошибку. Контрольный объект
остаётся неизменным. Оба процесса останавливаются при выходе. Ключи синтетические,
credentials.json имеет права 0600 внутри приватного временного каталога.

Пять групп: настройка и повтор; чтение через nginx без записи/удаления; multipart
через nginx с ETag, завершением и отменой; изоляция чужого бакета; запрет управления
бакетами читателю/загрузчику и удаления бакетов provision. Это не полный аудит
MinIO admin API, не TLS, не браузерная проверка и не публичное развёртывание.
